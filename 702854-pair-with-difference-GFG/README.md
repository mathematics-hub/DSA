# [Pair With Difference](https://www.geeksforgeeks.org/problems/find-pair-given-difference1559/1)
## Easy
Given an array, arr[]&nbsp;and an integer x, return true if there exists a pair of elements in the array whose absolute difference is x, otherwise, return false.Examples:Input: arr[] = [5, 20, 3, 2, 5, 80], x = 78
Output: true
Explanation: Pair (2, 80) have an absolute difference of 78.Input: arr[] = [90, 70, 20, 80, 50], x = 45
Output: false
Explanation: There is no pair with absolute difference of 45.
