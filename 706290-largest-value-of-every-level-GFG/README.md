# [Largest Value of Every Level](https://www.geeksforgeeks.org/problems/largest-value-in-each-level/1)
## Easy
Given a binary tree root[], find the largest values of all levels.
Examples:
Input: root[] = [1, 2, 3]
Output: [1, 3]
Explanation: There are two levels in the tree :
1. [1], max = 1
2. [2, 3], max = 3
Input: root[] = [4, 9, 2, 3, 5, 7]

Output: [4, 9, 7]
Explanation: There are three levels in the tree:
1. [4], max = 4
2. [9, 2], max = 9
3. [3, 5, 7], max = 7
