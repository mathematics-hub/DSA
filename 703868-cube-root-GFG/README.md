# [Cube Root](https://www.geeksforgeeks.org/problems/cube-root-of-a-number0915/1)
## Easy
Given a number n, find the floor of cube root of n.
Examples:
Input: n = 3
Output: 1
Explanation: Cube root of 3 is 1.442 = 1
Input: n = 8
Output: 2
Explanation: Cube root of 8 is 2
Constraints:1 &lt;= n &lt;= 105
