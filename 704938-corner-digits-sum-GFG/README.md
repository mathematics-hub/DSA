# [Corner Digits Sum](https://www.geeksforgeeks.org/problems/corner-digits1317/1)
## Easy
Given a positive integer n, find the sum of the first and the last digit of n.&nbsp;Examples:
Input: n = 12345
Output: 6
Explanation: 1st and last digits are 1 and 5.

Input: n = 98562
Output: 11
Explanation: 1st and last digits are 9 and 2. 

Constraints:1 ≤ n ≤ 109
