# [Sum of Natural Number Cubes](https://www.geeksforgeeks.org/problems/sum-of-first-n-terms5843/1)
## Easy
Given an integer n, calculate the sum of series 13 + 23 + 33 + 43 + … till n-th term.Examples:Input: n = 5
Output: 225
Explanation: 13 + 23 + 33 + 43 + 53 = 225Input: n = 7
Output: 784
Explanation: 13 + 23 + 33 + 43 + 53 + 63 + 73 = 784
