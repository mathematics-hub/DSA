# [Remove Consonants](https://www.geeksforgeeks.org/problems/c-program-to-remove-consonants-from-a-string1945/1)
## Easy
Given a string s, remove all consonants and return the modified string containing only vowels.
If the string does not contain any vowels, return an empty string.
Examples:
Input: s = "abEkipo"
Output: "aEio"
Explanation: a, E, i, o are only vowels in the string.

Input: s = "rrty"
Output: ""Explanation: There are no vowels.

Constraints1 ≤ n ≤ 105, n is length of the stringThe string should consist of only alphabets.
